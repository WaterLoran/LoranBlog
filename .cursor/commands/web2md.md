# web2md：将 Markdown 中的远程图片本地化

把指定 `.md` 里引用的**网络图片**下载到与文档同名的资源目录，并把正文中的链接改为本地相对路径。

## 使用方式

在对话中输入 **`/web2md`**，并在**同一条消息里**附上目标 Markdown 的**路径**（相对仓库根目录或绝对路径均可），例如：

`/web2md docs/某目录/文章.md`

若只给了文件名，先在仓库内解析出唯一路径或向用户确认。

---

## 工作流程概要（供执行者遵循）

1. **定位文件**：读取用户给出的 Markdown 路径，确认文件存在。
2. **收集图片 URL**：扫描正文中的图片引用，包括：
   - `![](https://...)`、`![alt](https://...)`
   - `[![alt](https://...)](https://...)`（整段为图片链接时按图片处理）
   - 仅处理明显为图片的 URL（路径或扩展名如 `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.svg` 等）；**不要**把普通文章超链接当成图片下载。
3. **资源目录**：令 `basename` = Markdown 文件名去掉 `.md` 后缀。在与该 `.md`**同级**创建文件夹 `basename/`（若已存在则沿用）。
4. **命名与去重**：按**上下文**（邻近图注、章节标题、文中说明）为每个文件起有意义的英文名（建议 `kebab-case`）。下载前列出 `basename/` 下已有图片文件名，**新文件名不得与已有文件重名**；若冲突则加后缀区分（如 `-2`、`-section-1`）。
5. **下载**：用终端 `curl -fsSL -o "..." "URL"`（或等价方式）下载；失败时换 User-Agent 或报告错误，不要静默跳过。
6. **改写 Markdown**：将远程地址替换为相对路径：`basename/文件名.ext`（路径相对**该 .md 所在目录**）。图片用标准 `![说明](basename/xxx.png)`；去掉仅用于打开原图的冗余外链包裹（若外层链接与内层图片 URL 相同）。
7. **自检**：文中不应再残留已迁移图片的远程 URL；`basename/` 内文件与正文引用一一对应。

## 约束

- 只改本次任务涉及的 Markdown 与新建/移动的图片；不做无关重构。
- 用户未提供路径时，说明用法并请其补充路径。

## 输出

完成后简短说明：新建或使用的资源目录、下载了哪些图、替换了哪些引用。
