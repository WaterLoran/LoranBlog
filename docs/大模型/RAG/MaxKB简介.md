# MaxKB简介

**MaxKB** 是一款开源的、面向企业级应用的智能体平台，其全称是"Max Knowledge Base"。它的核心定位是帮助企业和开发者快速搭建基于大模型的知识库问答系统和AI智能体应用。

它的设计理念可以概括为 **"开箱即用，伴随成长"** ，致力于降低企业落地AI应用的门槛。下面我从三个核心方面来介绍它：

------

### 1. 核心特点

MaxKB 之所以受到欢迎（全网累计安装量已超50万次，覆盖超过25万家企业用户），主要得益于以下几个关键特点：

- **模型中立，灵活对接**：它不绑定任何特定的大模型，支持对接多种主流模型。你可以选择：
  - **公有云模型**：如 OpenAI (GPT系列)、通义千问、智谱AI、Kimi 等。
  - **本地私有模型**：通过 Ollama 部署的本地模型（如 Llama、Qwen、DeepSeek等），满足数据安全要求。
  - **嵌入模型**：也支持对接多种向量模型，用于知识库的构建和检索。
- **开箱即用的RAG能力**：平台内置了完整的RAG（检索增强生成）流程。
  - **多格式文档导入**：支持直接上传 PDF、Word、Markdown、HTML、CSV 等多种格式的文档，也可以自动爬取指定网站的内容来构建知识库。
  - **自动化处理**：系统会自动对文档进行文本清洗、智能分块和向量化处理，开发者无需编写复杂代码。
- **强大的企业级权限管理**：这是它区别于许多轻量级开源项目的一大亮点。MaxKB 内置了基于角色的访问控制（RBAC）和多租户管理体系。
  - 可以实现精细化的权限控制，例如，通过标签和工作流，能做到**不同员工（如HR与IT）在问同一个智能体时，只能检索到各自部门相关的文档**，实现文档级别的权限隔离。
- **工作流编排与工具扩展**：支持通过可视化的方式编排复杂的AI工作流（Workflow），并支持通过MCP（模型上下文协议）使用外部工具，如查询数据库、调用API等，让智能体不仅能"回答问题"，还能"执行操作"。

------

### 3. 如何快速上手？

MaxKB 的设计非常注重易用性，官方提供了清晰的快速入门路径：

1. **一键部署**：最推荐的方式是使用 **Docker**，只需一行命令即可完成安装。

   bash

   ```
   # 示例Docker运行命令
   docker run -d --name=maxkb --restart=always -p 8080:8080 -v ~/.maxkb:/var/lib/postgresql/data registry.fit2cloud.com/maxkb/maxkb
   ```

   

   部署完成后，通过浏览器访问 `http://你的服务器IP:8080`（默认用户名/密码: `admin` / `MaxKB@123..`）即可进入控制台。

2. **配置模型**：在系统设置中，添加你选好的大模型（如OpenAI或通过Ollama接入的本地模型）和嵌入模型。

3. **创建知识库**：新建一个知识库，上传你的文档（如PDF、Word）或输入一个网站地址，系统会自动处理并建立索引。

4. **构建应用**：创建一个应用，将上一步的知识库关联起来，并选择你配置好的模型。你也可以在"高级编排"中通过拖拽方式设计更复杂的工作流。

5. **测试与发布**：在应用中进行命中测试，查看效果。没问题后，即可发布，并可通过嵌入代码的方式，快速集成到你的网站、企业微信、钉钉或飞书中。

总的来说，如果你正在为垂直领域的Agent应用寻找一个成熟、功能全面且能灵活对接各种模型的RAG知识库方案，MaxKB 是一个非常值得考虑的选项。它在模型中立性、权限管理和开箱即用方面做得比较均衡，能帮你省去不少从零搭建的底层工作。
