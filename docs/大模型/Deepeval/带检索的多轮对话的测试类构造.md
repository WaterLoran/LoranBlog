# 带检索的多轮对话的测试类构造

在DeepEval里，一个带检索的多轮对话，其核心是 **`ConversationalTestCase`** 类。它通过一组 `Turn` 对象来串联整个对话，每个 `Turn` 代表一次独立的“用户-助手”交互，并可以在其中（仅限助手Turn）携带本次生成所依赖的 `retrieval_context`（检索到的上下文）。

### 🧱 核心数据结构

*   **`ConversationalTestCase`**：代表一个完整的多轮对话测试用例[reference:0]。核心参数包括：
    *   `turns`：**（必需）** 一个包含多个 `Turn` 对象的列表，按对话顺序排列[reference:1]。
    *   `scenario`, `expected_outcome`：用于描述对话背景和预期目标的自然语言，便于理解与管理测试用例[reference:2]。
*   **`Turn`**：代表对话中的单次发言[reference:3]。
    *   `role`：**（必需）** 发言者角色，值只能是 `"user"` 或 `"assistant"`[reference:4]。
    *   `content`：**（必需）** 发言的具体文本内容[reference:5]。
    *   `retrieval_context`：**（可选，但评估RAG指标时强烈推荐）** 本次助手生成回答时所使用的检索上下文。该参数**只应在 `role="assistant"` 的 `Turn` 中提供**[reference:6]。
    *   `tools_called`：（可选）记录助手在该轮对话中调用的工具，用于Agent评估。

### ⚙️ 传参实践

下面是一个构建多轮RAG对话测试用例的完整代码示例，可以清晰地看到如何传递这些参数：

```python
from deepeval.test_case import ConversationalTestCase, Turn

# 构建一个多轮对话测试用例
test_case = ConversationalTestCase(
    scenario="用户正在向客服询问退货政策",
    expected_outcome="成功引导用户完成退货流程",
    turns=[
        # 第一轮：用户提问
        Turn(role="user", content="你好，我买了一件商品，但是不喜欢，想退货。"),
        
        # 第一轮：助手的回复及本次使用的检索上下文
        Turn(
            role="assistant", 
            content="您好，我们支持30天内无理由退货，请提供您的订单号。",
            retrieval_context=[ # 助手本次回答依赖的检索信息
                "我们的退货政策：用户可在收货后30天内申请无理由退货。",
                "客服在引导退货时，需要先获取用户的订单号。"
            ]
        ),
        
        # 第二轮：用户提供信息
        Turn(role="user", content="我的订单号是#12345。"),
        
        # 第二轮：助手基于新的上下文回复
        Turn(
            role="assistant", 
            content="收到，订单#12345已为您创建退货申请，请将商品寄回。",
            retrieval_context=[ # 本次回答依赖的检索信息，可能不同
                "根据订单号#12345，该商品符合退货条件。",
                "退货申请创建成功后，需要告知用户寄回地址。"
            ]
        ),
    ]
)
```

### 🎯 评估指标

DeepEval 专门为多轮RAG场景提供了指标，它们会**考虑整个对话的历史上下文**，来评估助手的表现[reference:7]。

| 指标名称                          | 评估核心                                                     | 典型应用场景                                                 |
| :-------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **TurnFaithfulnessMetric**        | 单轮助手的回答是否**忠实**于**其对应的** `retrieval_context`，不产生幻觉。 | 评估客服机器人在回答具体问题时，是否严格基于当时的检索结果。 |
| **TurnContextualRecallMetric**    | 在特定一轮对话中，用户问题的答案信息是否被**检索到**并体现在助手的回答中。 | 判断检索器是否漏掉了关键信息，导致助手无法回答。             |
| **TurnContextualRelevancyMetric** | 检索到的上下文内容是否与**该轮**的用户问题相关，有没有引入噪音。 | 优化检索系统的准确性，避免给生成器提供无关信息。             |
| **TurnContextualPrecisionMetric** | 评估**该轮**中，`retrieval_context` 里那些相关的片段是否被排在了更重要的位置。 | 精细化评估检索结果的排序质量。                               |
| **KnowledgeRetentionMetric**      | 助手在后续对话中，是否能够**回忆起并利用**在**前面轮次中由用户明确提供的信息**。 | 评估客服在连续对话中，是否记得用户之前提过的订单号或个人信息[reference:8]。 |
| **TurnRelevancyMetric**           | 评估助手在**整个对话上下文中**的每一轮回复是否都切题，没有偏离主题。 | 确保聊天机器人不会突然说出与当前话题无关的话[reference:9]。  |

### 💻 完整代码示例

这是一个使用 `ConversationalTestCase` 和 `TurnFaithfulnessMetric` 评估的完整流程：

```python
import os
from deepeval import evaluate
from deepeval.metrics import TurnFaithfulnessMetric
from deepeval.test_case import ConversationalTestCase, Turn

# 1. 准备测试数据：模拟客服对话
test_cases = [
    ConversationalTestCase(
        turns=[
            Turn(role="user", content="你好，我买的商品不喜欢，想退货。"),
            Turn(role="assistant", content="您好，我们支持30天内无理由退货。", 
                 retrieval_context=["我们的退货政策：用户可在收货后30天内申请无理由退货。"]),
            Turn(role="user", content="那怎么操作呢？"),
            Turn(role="assistant", content="您可以在订单页面点击“申请退货”，或联系客服。", 
                 retrieval_context=["退货操作指南：用户登录后，在订单详情页可自助申请退货。"])
        ]
    ),
]

# 2. 配置并运行指标
faithfulness_metric = TurnFaithfulnessMetric(threshold=0.7)
results = evaluate(test_cases, [faithfulness_metric])

# 3. 查看结果
for result in results:
    print(f"Metric: {result.metrics_results[0].name}, Score: {result.metrics_results[0].score}")
```

### 🚀 运行与解释

1.  **执行评估**：使用 DeepEval 的命令行工具运行测试文件：`deepeval test run <your_test_file>.py`。
2.  **输出解读**：
    *   评估指标会为每个 `role="assistant"` 的 `Turn` 独立计算分数，并给出一个总分。
    *   例如，`TurnFaithfulnessMetric` 分数为 0.8，表示在 80% 的助手回复轮次中，回答忠实于其提供的 `retrieval_context`，没有出现严重的“幻觉”。

### 💎 总结

简单来说，评估多轮RAG对话的关键在于：

1.  使用 `ConversationalTestCase` 作为测试用例，用 `Turn` 对象串联每一轮对话。
2.  为每个 `role="assistant"` 的 `Turn` 提供独立的 `retrieval_context`，作为评估其回答的“参考依据”。
3.  选用 DeepEval 提供的专用多轮RAG指标，对检索和生成质量进行逐轮评估。
