# 对话系统评估案例

我们直接使用 **Kimi API 作为被测对话系统**，然后用 DeepEval 对它进行对话质量评估。下面给出完整可直接运行的代码。

---

## 📦 第一步：安装依赖

```bash
pip install deepeval 'openai>=1.0'
```

---

## 🔑 第二步：获取 Kimi API 密钥

1. 访问 [Kimi 开放平台](https://platform.moonshot.ai/)，注册并创建 API Key。
2. 设置环境变量或直接在代码中填写（建议使用环境变量）。

---

## 📝 第三步：完整测试代码

创建一个文件 `test_kimi_chatbot.py`，内容如下：

```python
# test_kimi_chatbot.py
import os
from openai import OpenAI
from deepeval import evaluate
from deepeval.metrics import KnowledgeRetentionMetric, TurnRelevancyMetric
from deepeval.models import KimiModel
from deepeval.test_case import ConversationalTestCase, Turn

# DeepEval 指标里的「裁判模型」默认走 OpenAI，需显式换成 Kimi，否则会要求 OPENAI_API_KEY
_judge_llm = KimiModel(model="moonshot-v1-8k")

# ================== 1. 封装 Kimi API 为对话系统 ==================
class KimiChatBot:
    """封装 Moonshot (Kimi) API 为简单的对话系统，支持多轮对话"""
    def __init__(self, api_key: str = None, model: str = "moonshot-v1-8k"):
        self.api_key = api_key or os.environ.get("MOONSHOT_API_KEY")
        if not self.api_key:
            raise ValueError("请设置 MOONSHOT_API_KEY 环境变量或传入 api_key")
        self.client = OpenAI(
            api_key=self.api_key,
            base_url="https://api.moonshot.cn/v1"
        )
        self.model = model
        self.conversation_history = []  # 存储完整对话历史（OpenAI 格式）

    def chat(self, user_input: str) -> str:
        """发送用户消息，返回模型回复"""
        self.conversation_history.append({"role": "user", "content": user_input})
        response = self.client.chat.completions.create(
            model=self.model,
            messages=self.conversation_history,
            temperature=0.7
        )
        assistant_message = response.choices[0].message.content
        self.conversation_history.append({"role": "assistant", "content": assistant_message})
        return assistant_message

    def reset(self):
        """重置对话历史（开始新对话）"""
        self.conversation_history = []

# ================== 2. 定义评估指标 ==================
# 对话相关性：评估每一轮回复是否与当前话题相关
relevancy_metric = TurnRelevancyMetric(threshold=0.5, model=_judge_llm)

# 知识保留：评估模型是否记住了用户之前提供的信息
memory_metric = KnowledgeRetentionMetric(threshold=0.5, model=_judge_llm)

# ================== 3. 准备测试对话 ==================
# 初始化被测机器人
bot = KimiChatBot()  # 确保 MOONSHOT_API_KEY 已设置

# 模拟一个需要记忆和上下文理解的多轮对话
print("=== 开始与 Kimi 对话 ===")

# 第一轮：用户提供名字和意图
user_msg1 = "你好，我叫李明，我想预订一张明天从北京到上海的机票。"
assistant_msg1 = bot.chat(user_msg1)
print(f"用户: {user_msg1}\nKimi: {assistant_msg1}\n")

# 第二轮：测试记忆（是否还记得用户的名字）
user_msg2 = "请问我的名字是什么？"
assistant_msg2 = bot.chat(user_msg2)
print(f"用户: {user_msg2}\nKimi: {assistant_msg2}\n")

# 第三轮：测试上下文修改
user_msg3 = "改成后天从北京到深圳。"
assistant_msg3 = bot.chat(user_msg3)
print(f"用户: {user_msg3}\nKimi: {assistant_msg3}\n")

# 第四轮：测试无关问题后是否还能回到原任务
user_msg4 = "今天天气怎么样？"
assistant_msg4 = bot.chat(user_msg4)
print(f"用户: {user_msg4}\nKimi: {assistant_msg4}\n")

# 第五轮：回到预订任务，检查是否丢失了之前的修改
user_msg5 = "那我刚才说的机票是什么时候的？"
assistant_msg5 = bot.chat(user_msg5)
print(f"用户: {user_msg5}\nKimi: {assistant_msg5}\n")

# ================== 4. 构造 DeepEval 对话测试用例 ==================
# 将上述对话转换为按轮次的 Turn 列表（user / assistant 交替）
conversation_test = ConversationalTestCase(
    turns=[
        Turn(role="user", content=user_msg1),
        Turn(role="assistant", content=assistant_msg1),
        Turn(role="user", content=user_msg2),
        Turn(role="assistant", content=assistant_msg2),
        Turn(role="user", content=user_msg3),
        Turn(role="assistant", content=assistant_msg3),
        Turn(role="user", content=user_msg4),
        Turn(role="assistant", content=assistant_msg4),
        Turn(role="user", content=user_msg5),
        Turn(role="assistant", content=assistant_msg5),
    ]
)

# ================== 5. 运行评估 ==================
print("=== 开始 DeepEval 评估 ===")
evaluate([conversation_test], [relevancy_metric, memory_metric])

```

## 🔧 可选：增加更多对话评估指标

DeepEval 还提供了其他对话相关指标，你可以按需添加：

```python
from deepeval.metrics import (
    RoleAdherenceMetric,      # 角色一致性（需预设系统提示词）
    ConversationCompletenessMetric,  # 对话完整性
    ConsistencyMetric         # 跨轮次一致性
)

# 示例：评估 Kimi 是否始终扮演客服角色
role_metric = RoleAdherenceMetric(
    role="你是一个机票预订客服助手",
    threshold=0.6
)

# 添加到 evaluate 中
evaluate([conversation_test], [relevancy_metric, memory_metric, role_metric])
```

## 💡 代码说明

| 部分                  | 说明                                                         |
| :-------------------- | :----------------------------------------------------------- |
| **KimiChatBot 类**    | 封装 Kimi API，自动维护对话历史，支持多轮。                  |
| **对话模拟**          | 硬编码了 5 轮对话，覆盖记忆、修改、干扰、恢复等典型场景。    |
| **DeepEval 测试用例** | 将每轮的 `(用户输入, 模型输出)` 转换为 `LLMTestCase`，再打包成 `ConversationTestCase`。 |
| **评估指标**          | `ConversationRelevancyMetric` 检查每轮是否跑题；`KnowledgeRetentionMetric` 检查是否记住关键信息。 |
| **运行命令**          | 必须使用 `deepeval test run`，而不是 `python`，这样才会调用 DeepEval 的 CLI 评估引擎。 |

## 🎯 总结

你现在拥有一个**直接调用 Kimi API 作为被测对话系统**的 DeepEval 测试脚本。可以：
- 修改对话内容以测试你关心的场景。
- 增加更多评估指标（角色、完整性等）。
- 自动化运行（例如集成到 CI 中）。

如果 Kimi API 调用较慢，可以适当增加超时设置，或切换到 `moonshot-v1-32k` 模型。
